# Privacy Policy

Last updated: Nov 13, 2026

The extension is designed to run in the browser and keep ordinary settings and feature state in local browser extension storage.

## Data stored locally

The extension uses local browser extension storage for settings, feature preferences, cached item data, UI state, notification settings, and optional 2FA autofill data.

## Optional 2FA autofill

If you choose to save a 2FA secret, it is stored in your browser extension storage. When the password lock option is used, the secret is encrypted with a password-derived key before storage. The password itself is not stored.

## Remote requests

LITE contacts Roblox and Rolimons over HTTPS for item values, trade-page helpers, Rolimons trade-ad posting, and related client-side features. It does not contact nevos-extension.com APIs, Routility, or roautotrade.com.

## Problem reports

The popup's "Report a problem" builds a report for you to copy and paste into our Discord. It contains what you typed plus the parts you leave ticked: diagnostics (extension version, browser, settings you changed, and the extension's last errors and failed requests, with addresses cut to host and path) and page details (page address and title, window size). The popup shows exactly what is in it.

LITE never sends a report anywhere. Until you copy one, the last errors and failed requests stay in browser session storage, which the browser clears when it closes.

## No sale of user data

We do not sell user data. We do not use extension data for advertising or unrelated profiling.

## Cookies

The extension manifest does not request cookie permissions. The website may be served as a static site and does not require cookies for the extension download pages.

## Permissions

The extension requests permissions needed for its features, including storage, alarms, notifications, and access to the supported Roblox and Rolimons domains declared in the extension manifest.

## Contact

For privacy questions, support, or removal requests, contact us through the official Discord linked on the website.
